RESUEN DE FUNCIONES 

El programa cuenta con funciones para ingresar el nombre del estudiante, seleccionar su tanda y asignatura, introducir las calificaciones de los cuatro períodos y verificar la asistencia. También permite registrar las materias y calcular sus promedios, mostrar el resumen general con las asignaturas aprobadas, en recuperación o reprobadas, validar los datos ingresados, limpiar el formulario y salir de la aplicación.
